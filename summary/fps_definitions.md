# FPS definitions

- Engine FPS: `1000 / 91.636492 ms = 10.912683` images/s.
- Transfer-inclusive FPS: `1000 / 96.902103 ms = 10.319693` images/s.
- Latency-derived pipeline FPS: `1000 / 148.077650 ms = 6.753214` images/s.
- Wall-clock pipeline FPS: `192 / 28.995672 s = 6.621678` images/s.

Engine FPS is not labeled application FPS. Warmups and all offline analysis are excluded.
